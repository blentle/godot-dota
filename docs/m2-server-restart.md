# 开发局服务器进程重启恢复

## 范围与运行

构建标识 `m2-network-10`，存档结构版本 1。共享开发服务器可选择启用本机权威存档；默认不写存档，正式 `--server` 入口仍未开放。

```sh
godot --headless --path game --script res://tests/network_server.gd -- --shared --players=2 --port=27883 --checkpoint=/实际私有目录/authority.bin
python3 tools/test_server_restart.py --godot /实际路径/Godot
godot --headless --path game --script res://tests/test_checkpoint.gd
```

存档父目录须已存在且由运行者管理；同一文件只能由一个服务器进程使用。重启时使用相同文件、构建、内容标识和席位数。存档损坏或参数不兼容会阻止启动，不静默覆盖旧局。没有存档时创建新局；存档中全部凭据过期时允许创建新局。

## 状态与确认顺序

存档保存权威单位、生命批次、攻击前摇、订单路径、弹道、兵线、召唤、个人账本和背包、技能冷却、结算、已处理命令序号及最后确认。显示快照不足以恢复模拟，因此由独立字段清单、世界适配器、结构校验器、存储器和生命周期协调器组合完成。

处理握手、就绪、恢复、命令或离场后，先保存再发送响应；保存失败立即停止服务，不确认未保存的交易。测试覆盖购买已保存但确认丢失后的重复命令，保证不重复扣费或复制物品。未开局时保存空状态；不提供装载阶段恢复。

运行期间另每 60 个权威 tick 保存一次，断开连接时也保存。意外终止可能回退最近约一秒模拟中的移动与战斗；已确认命令的状态已同步保存。恢复后先暂停所有席位，首位原玩家恢复后继续推进；英雄原订单取消，旧表现事件不重放。玩家命令与画面沿用已有重连流程。

在线席位在保存时得到绝对时间起算的 30 秒恢复期限；已断线席位只保存剩余期限。无人重连时再次保存或反复重启不能延长期限。跨进程期限依赖系统时钟，尚未处理管理员调时或跨主机时钟偏差。客户端仍受原有 25 秒恢复窗口限制。

## 文件边界

文件使用固定标识、SHA-256 完整性摘要和不含对象的 Variant 值；读取前限制 8 MiB，恢复前校验版本、字段类型、有限数值、席位和引用。摘要检测意外损坏，不构成恶意修改防护。凭据会写入此可选存档，不能公开、提交 Git 或放入公共下载目录。

先写同目录 `.pending` 文件并 flush，再替换正式文件；macOS/Linux 写入时限制文件为属主读写。保存失败返回明确原因。该实现仅验收进程崩溃，不承诺断电、磁盘故障或目录未同步时的持久性，也不提供文件锁、加密和自动备份。
