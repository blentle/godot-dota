# 经典英雄粒子基础表现

本轮继续优先英雄外观，不新增玩法或修改生命、魔法、冷却、金币等规则。

## 接入范围

从已导入的原始模型 JSON 读取 `ParticleEmitters2`，直接使用原始纹理、发射参数与动画时间轨，没有生成通用火焰来替代英雄美术。配置统计见 `references/classic-particle-coverage.json`：98 个模型包含 305 个类型 2 发射器，其中 31 个喷发型、69 个带拖尾、99 个使用多格图集。这些是模型/发射器配置数量，不是正式英雄完成数。

支持的基础表现包括：

- 连续发射和按关键帧切换的一次性 Squirt 喷发；重播同一动作可再次喷发，全局喷发则不会因动作切换而多发。可见性关闭后停止新发射，存量继续老化。
- 原始宽长范围、速度、变化幅度、纬度、重力和寿命；沿源骨骼节点的世界变换发射。
- 世界空间粒子留在原世界位置；ModelSpace 粒子随源节点移动。
- 相机朝向粒子、XYQuad、头部和速度拖尾；三阶段颜色、透明度、大小；生存/衰减阶段图集动画。
- 预制原图和队色/队伍光晕纹理。队色已经读取独立图像后，不再按组合图集二次切割。
- Blend、Additive、Modulate 和 AlphaKey 的基础材质设置；modulate2x 仍以乘色近似，尚未完成精确混合验收。

类型 2 的头尾标志由既有转换器保留为位标志：1 为头部、2 为拖尾、3 为两者。普通材质与粒子材质的 FilterMode 编号并不相同，分别解释。

## 模块职责

| 文件 | 职责 |
|---|---|
| `particle_state.gd` | 可复用粒子状态、运动、寿命、分段颜色/大小与图集帧 |
| `particle_system.gd` | 原始轨道采样、固定步长、发射调度、对象池和上限 |
| `particle_batch.gd` | 一个发射器一个绘制批次，生成头部/拖尾顶点、颜色和 UV |
| `model_view.gd` | 骨骼更新后推进粒子表现，暂停时不推进寿命 |

粒子数据使用世界坐标时，绘制批次必须将世界变换设为单位矩阵；不能在父模型坐标下再次缩放和旋转。顶层节点切换会保留旧变换，本轮显式清零以防二次变换。

## 数量和时间边界

每模型使用 512 个可复用粒子状态，所有发射器共享这个上限；达到上限时丢弃额外发射并记录 `dropped`，不持续分配粒子节点。头和尾可以共用一个状态，绘制为两个四边形。

模拟步长固定为 1/60 秒，保留发射与时间余量。单次跳时最多追算两秒，超过部分记录为 `dropped_time`，避免后台恢复时无界追帧。零时间更新不发射、不老化；重新绑定清空旧批次和旧池，不能累加容量。

随机种子固定用于当前美术校准与截图复现；不把该表现随机数接入权威规则。

## 验证

- `test_classic_particles.gd`：连续数量、喷发关键帧去重、隐藏后回收、空间语义、零时间更新、512 上限和长跳时有界处理。
- `test_classic_particle_geometry.gd`：头尾三角形数、世界位置、图集取格、三阶段颜色、RGBA8 量化、拖尾长度、队色图 UV 及回收后清除旧几何。
- 214 个去重后的原始本体/头像模型继续通过加载与多动作推进检查。
- 工程统一规则和场景回归通过；本轮未重跑十客户端网络长局或十人图形端粒子压力测试；权威规则和网络协议没有改动，粒子上限回归不能替代图形压力验收。
- macOS Apple Silicon 实机截取影魔 0 秒和 0.45 秒表现。截图只证明当前实现可显示，不能代替与 Warcraft III 1.26 的逐帧视觉对照。

复现：

```sh
.tools/Godot.app/Contents/MacOS/Godot --path game --script res://tests/capture_classic_motion.gd -- --classic-hero=Nfir --capture-prefix=/tmp/shadowfiend
python3 tools/classic_art/particle_coverage.py
```

截图工具现在也清空粒子池，以免重置骨骼时钟后遗留上一轮粒子。

## 明确缺口

已导入资源还包含 15 个旧式 `ParticleEmitter`、39 个 `RibbonEmitter`，本轮尚未实现。发射节点在一帧内部的骨骼运动插值、部分节点标志、三轴非均匀缩放、拖尾 UV 方向及原版精确混合仍待逐模型校准。

粒子密度、大小、颜色与光照尚未逐英雄对照原版截图/录像；本轮没有宣称达到 95% 或完整还原。地形、树与建筑仍为占位美术，整体 HUD 字体和部分坐标仍待验收。Windows、Linux 未实测。
