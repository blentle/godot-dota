# 经济、商店与装备开发切片

本切片使用四件开发物品验证购买到战斗的闭环，不代表 6.83d 正式装备、商店布局或经济规则已经完成。

## 操作

进入三路兵线演练后，按 **B** 或点击背包下方“商店”打开面板。位于近卫基地中心 `(-37, 0, 37)` 的 11 单位范围内且存活时，可以购买和出售。出生点位于该范围内。

点击购买后，物品进入第一个空背包格，装备属性即时生效。点击背包中的物品，再点击商店的“出售”按钮，返还原价的 50%，小数向下取整。B、Esc 或关闭按钮关闭商店；Esc 在商店关闭后才打开暂停菜单。

交易期间战场继续运行，移动出交易范围或阵亡会立即禁用交易按钮并说明原因。商店面板拦截鼠标，面板外仍可操作地面。打开商店时，攻击和技能键不会触发世界命令。

## 开发参数

兵线模式初始金币 300，每累计一秒获得 1 金币，阵亡期间也有收入；暂停或对局结束后停止计时。单对手训练仍从零金币开始，靠击杀取得金币，不发放被动收入。

| 物品 | 价格 | 属性 |
| --- | ---: | --- |
| 训练短剑 | 100 | 攻击 +12，多件叠加 |
| 训练护衣 | 150 | 生命上限 +150，多件叠加 |
| 训练护符 | 120 | 魔法上限 +80，多件叠加 |
| 训练行靴 | 125 | 移动速度 +1，多双不叠加 |

背包固定六格。购买上限装备不会恢复当前生命或魔法；出售降低上限时，当前值夹取到新上限。复活保留装备并按装备后的上限恢复资源。装备修改攻击力和实际导航移动速度，界面读取同一权威状态。已发出的投射物继续使用发射时的伤害快照。

## 模块边界

- `item_catalog.gd`：物品目录与开发参数。
- `economy_system.gd`：交易前置校验、六格库存、金币和属性重算。
- `training_world.gd`：对局结束检查与购买、出售命令入口。
- `shop_panel.gd`：商店内容、交易状态、出售选择和输入反馈。
- `classic_hud.gd`：背包格、商店入口、实时属性展示。

交易按对局状态、存活、距离、物品、容量、余额依次校验；全部通过后才变更金币、库存及属性。出售校验槽位并清空原槽，防止重复退款。

## 验证与缺口

规则测试覆盖余额不足、满包、非法物品和槽位、距离、死亡、重复出售、属性叠加、移速上限、真实伤害和移动、复活、持续收入以及结束冻结。场景测试用真实视口鼠标输入完成购买、背包选择、出售，并验证商店右键不穿透。

macOS Godot 4.7.2 的规则、双模式场景回归与固定截图检查通过。Windows/Linux 尚未实测。

尚未实现配方合成、消耗品、主动装备、物品冷却、仓库、信使、丢弃拾取和正式物品数据。背包暂用文字缩写，正式图标和商店视觉还原留待素材校对后完成。
