# 训练战斗闭环：M2 的首个开发切片

本轮新增一个可重复操作的训练战斗流程，为正式英雄系统验证命令、伤害和生命周期边界。不是完整 M2，不是已完成的 DotA 英雄。

## 操作

- 右键红色训练对手，或按 A / 点击“攻击”：追击并在范围内自动普攻。
- 按 Q / 点击“震击”：在 5 世界单位内造成训练伤害并眩晕对手。
- S 停止、H 保持：取消移动与普攻前摇；近距离对手仍会攻击，需要移动离开以脱战。
- 右键空地：取消追击并移动；仍保留 M、F1、方向键、滚轮、小地图操作。
- Esc/F10 暂停：冻结伤害、魔法恢复、冷却与复活计时。

## 当前训练参数

| 参数 | 玩家训练卫兵 | 训练对手 |
|---|---|---|
| 生命 | 600 | 240 |
| 魔法 | 240，每秒恢复 3 | 无 |
| 普攻伤害 | 55 | 45 |
| 攻击间隔 | 1 秒 | 1.4 秒 |
| 攻击前摇 / 距离 | 0.28 秒 / 2.4 | 0.28 秒 / 2.4 |
| 复活 | 死亡后 5 秒，恢复生命和魔法 | 死亡后 8 秒 |

震击：伤害 80、消耗 60 魔法、冷却 6 秒、距离 5、眩晕 1.5 秒。击杀对手获得 50 训练金币，单次死亡不重复奖励。对手站在出生位置，只对近距离玩家反击；没有追击 AI。

以上均为开发参数，不来自已核验的 6.83d 地图。金币和统计仅存在本次内存会话，重启清空。

## 已实现反馈

玩家与对手有头顶血条。底部生命/魔法条显示实际训练状态，技能按钮显示剩余冷却；魔法不足、冷却中、未选中、暂停、死亡时按适用条件禁用指令。对手状态区显示生命、眩晕或复活倒计时。顶部显示训练金币，单位面板显示击杀和阵亡。

## 验证与限制

Godot 自动测试覆盖：责任链拒绝无副作用、攻击前摇、距离变化导致落空、停止/眩晕打断、技能耗费与冷却、奖励幂等、双方复活、追击后完成击杀。原有导航、场景装配、HUD 点击隔离与菜单焦点回归继续通过。

正式英雄数据、攻击类型、护甲、魔抗、完整施法前后摇、战争迷雾和网络仍未完成。后续已加入三路兵线、塔攻击、基地胜负与开发装备，分别见 m2-lanes.md、m2-economy.md。当前 A 是追击指定目标，不等价于正式攻击移动；震击仍为单目标训练效果，并非范围伤害实现。

源代码拆分详见 code-structure.md。下一步在取得可信原版数据后，将首个正式英雄作为数据与技能接入样本，同时逐步扩展单位集合和伤害类型。
