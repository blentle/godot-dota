# 地图时间静态证据

本轮只读扫描固定摘要地图及提取配置，没有执行 JASS，也没有修改游戏时钟、昼夜规则或服务器协议。机器报告见 `references/classic-time-evidence.json`。

## 来源与可复现方式

地图 SHA-256 为 `326d7ea8fb2bf20bd540259ebc3e80d398cf1be79fe1827691927c9008107495`。扫描前验证地图文件及 `references/dota-683d-archive.json` 已记录的 `scripts/war3map.j`、`war3mapmisc.txt` 摘要，避免只给当前文件计算摘要就自称来源可信。副本仍未独立核实为官方发行版本。

运行 `python3 -m tools.classic_art.time_evidence` 生成报告；验证失败返回非零，不覆盖报告。调用位置使用 CRLF/CR 正规化为 LF 后的 1 起始行号，不是原始字节偏移。原始缓存仍在忽略目录。

条件栈保留 if、elseif、else 的源分支标签；else 的前置否定以及复杂短路逻辑没有求解，不能把标签列表当完整触发谓词。动态调用、计时器和多层注册链也未构建完整可达性分析。

## 与模型动画的关系

报告记录三种族模型文件摘要、原始序列区间、纹理和 TextureAnims 数据，供与已有 0/15/30 秒截图对照。源模型 Stand 区间为 [0,60000]，Stand Alternate 为 [67500,127500]；这是模型毫秒时间轴，不是地图小时。

本轮没有足够证据把地图 6 点或 0.625 倍率换算成某个正式模型帧，也没有推断实际昼夜周期。仅凭 DayLength=300.0 或模型片段长 60 秒均不足以确认映射，当前预览循环保持原实现。

## 工具及验证边界

词法扫描区分注释、带转义字符串和代码，保留函数归属、调用文本、行号与嵌套条件。受控测试先因模块缺失失败，实现后通过；覆盖混合换行、注释/字符串误匹配、相似函数名、跨行调用、嵌套分支及字符串未闭合。来源测试验证错误摘要被拒绝。

全部 Python 工具测试、资源来源检查及 197 个源文件行数检查通过。独立只读审查未发现当前固定来源下的重要问题。这不是完整 JASS 解析器、执行器或控制流证明；没有游戏逻辑改动，本轮未追加 Godot 战斗长局或图形截图测试。

## 后续核对：注册点与局部同名变量

`VU2` 在正规化第 32791 行将触发器注册为 0.25 秒周期检查，第 32792 行绑定 `IU2`；`IU2` 的设时刻/倍率调用位于 `if r==0 then` 分支，r 来自 `TimerGetRemaining(OL)`。这是倒计时归零的静态线索，仍不等于全部模式入口已验证。

`BK2` 在第 29141–29150 行注册十个玩家的 `-time` 聊天事件，第 29151 行绑定 `BC2`。`BC2` 从聊天字符串第 5 位后提取参数，使用 `S2I` 转为局部整数 GW1，若小于 0 或大于 24 则设为 0，再写入时刻。BK2 自身的调用条件尚未完整确认，不能称该命令在所有正式对局均可用。

重要修正：前述“GW1 直接赋值 13 处”仅表示同名标识符的 set 语句数，不是同一个变量的数据流。源脚本另有 20 处同名局部初始化；BC2 的 GW1 是本函数局部变量。机器报告新增 `local_initializers` 与作用域警告，避免将混淆命名的不同局部变量误关联。没有从这些线索推断出正式昼夜映射。

## 注册入口的条件补充

机器报告的 `direct_entry_calls` 现在复用词法扫描器记录时间函数及 VU2/BK2 的一层直接调用与条件，不扩展为完整可达性分析。

- `main` 调用 BK2 时位于 `if(bj_isSinglePlayer and AR2())then`；AR2 的具体语义未求解。
- `C02` 调用 BK2 时位于 `if PE0==false then`；不能因存在单机入口就忽略这一条其他入口。
- `W82` 调用 VU2 时位于 `if CN==false and BN==false then`；R02 中位于 `if J2 then`。
- YE2、KW2 中的 VU2 调用没有局部 if 栈，并不表示这两个函数会无条件执行；它们自己的注册/调用入口仍需核对。

原报告的 4/3/14 时间原语计数保持不变；新增调用单独列出，避免把辅助入口数量混入原始调用统计。游戏时钟仍未改动。
