# 地图时间静态证据

本轮只读扫描固定摘要地图及提取配置，没有执行 JASS，也没有修改游戏时钟、昼夜规则或服务器协议。机器报告见 `references/classic-time-evidence.json`。

## 来源与可复现方式

地图 SHA-256 为 `326d7ea8fb2bf20bd540259ebc3e80d398cf1be79fe1827691927c9008107495`。扫描前验证地图文件及 `references/dota-683d-archive.json` 已记录的 `scripts/war3map.j`、`war3mapmisc.txt` 摘要，避免只给当前文件计算摘要就自称来源可信。副本仍未独立核实为官方发行版本。

运行 `python3 -m tools.classic_art.time_evidence` 生成报告；验证失败返回非零，不覆盖报告。调用位置使用 CRLF/CR 正规化为 LF 后的 1 起始行号，不是原始字节偏移。原始缓存仍在忽略目录。

## 已证实的静态事实

| 内容 | 结果 |
| --- | --- |
| 地图 DayLength 配置 | 300.0 |
| SetFloatGameState 调用 | 4 处 |
| SetTimeOfDayScale 调用 | 3 处 |
| SuspendTimeOfDay 调用 | 14 处 |
| GW1 直接赋值 | 13 处 |

`HA1` 和 `main` 都包含设为 6 点、恢复时间、倍率 0.5 的连续调用。`HA1` 在 `InitTrig_Map` 内有直接调用；`main` 没有扫描到普通直接引用，不表示引擎不会调用入口。

`IU2` 包含设为 6 点、恢复时间、倍率 0.625，在 `VU2` 中有函数引用；`BC2` 使用 GW1 设置时间，在 `BK2` 中有函数引用。报告记录这些位置，未由此宣称它们属于某个已确定模式、技能或实际开局分支。

条件栈保留 if、elseif、else 的源分支标签；else 的前置否定以及复杂短路逻辑没有求解，不能把标签列表当完整触发谓词。动态调用、计时器和多层注册链也未构建完整可达性分析。

## 与模型动画的关系

报告记录三种族模型文件摘要、原始序列区间、纹理和 TextureAnims 数据，供与已有 0/15/30 秒截图对照。源模型 Stand 区间为 [0,60000]，Stand Alternate 为 [67500,127500]；这是模型毫秒时间轴，不是地图小时。

本轮没有足够证据把地图 6 点或 0.625 倍率换算成某个正式模型帧，也没有推断实际昼夜周期。仅凭 DayLength=300.0 或模型片段长 60 秒均不足以确认映射，当前预览循环保持原实现。
