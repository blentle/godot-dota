# 双进程网络适配切片

当前交付是单席位、本机回环的开发验证：独立 Godot 服务端推进三路训练世界，独立客户端发送操作并读取快照。普通游戏窗口仍使用离线世界，没有接入本网络适配器。不能据此宣称十人对战、正式服务器或 M2 全部完成。

## 运行

指定 Godot 4.7.2 可执行文件，运行自动验证：

```sh
python3 tools/test_network_pair.py --godot .tools/Godot.app/Contents/MacOS/Godot
godot --headless --path game --script res://tests/test_network_authority.gd
```

其他系统把 `--godot` 改为实际可执行文件路径。脚本自动选择本机 UDP 端口，等待服务端就绪，先后启动两个客户端进程，确认退出后席位释放、第二次连接获得全新世界；超时或验证失败会报错，最终回收自己启动的服务端。端口选择存在操作系统释放与绑定间的竞争，冲突会明确失败。

手动开发入口为 `res://tests/network_server.gd` 和 `res://tests/network_client.gd`，都接受 `-- --port=27883`。客户端是自动验证程序，不是可操作的图形客户端。普通 `--server` 仍拒绝启动，防止误认为已具备部署能力。

## 模块责任

| 文件 | 责任 |
| --- | --- |
| `network/dev_protocol.gd` | JSON 解码、字段与类型白名单、版本身份 |
| `network/dev_authority.gd` | 连接控制权、序号、命令分发及固定步模拟 |
| `network/world_snapshot.gd` | 从规则世界提取独立值快照 |
| `network/dev_server.gd` | ENet 收发、连接超时、流量限制、定期快照 |
| `network/dev_client.gd` | 发送命令、接收与保存最新快照，不运行规则模拟 |
| `tools/test_network_pair.py` | 真实进程启动、超时、日志检查与回收 |

## 当前契约

服务端仅绑定 `127.0.0.1`，最多接受四个传输连接，仅一席位可完成握手。握手包含协议版本、开发构建标识、清单文件 SHA-256 和开发角色 ID；清单哈希不是完整资源包校验，也不构成认证。成功后连接绑定 `player` 控制权，重复握手和其他连接抢占均拒绝。

命令包含 `type=command`、固定开发比赛标识、从 1 开始的连续 `sequence`、`command` 与可选 `target`。支持移动、攻击、停止、保持、三种训练施法、购买和出售，全部调用已有规则入口；不允许客户端传入控制实体、伤害或金币。移动坐标校验类型、有限值和地图边界。

每个合法命令序号只执行一次；最近一次重复序号返回缓存确认，过期或跳号拒绝。格式校验失败不占用序号；规则层拒绝的合法命令占用序号并返回原因。最近确认只缓存一条，重复包即使更换载荷也不会再次执行。

权威规则每步推进 1/60 秒，每六步发一次全量快照；目前命令、确认和快照均用可靠 ENet 通道。快照包括 tick、确认序号、单位基础状态、金币、装备及结算。客户端拒绝旧 tick，不预测命中或本地扣费。此频率为开发验证值，不是最终性能预算。

单个入站命令最大 4096 字节，每连接每秒最多 120 包，每次物理帧最多处理 128 包。超限连接断开；握手最长五秒，十秒没有入站消息也断开。当前没有心跳，不能用于长期挂机。拥有者断开即销毁开发世界；下一次连接创建新世界，不属于重连恢复。

## 验证结果与缺口

已在 macOS Apple Silicon / Godot 4.7.2 上通过：

- 规则测试：错误版本、席位冲突、跨连接控制、额外字段、跳号、重复扣费、旧序号、异常坐标、业务失败确认、快照隔离及断开清理。
- 两个真实进程：拒绝错误版本、合法握手、购买、重复购买只扣一次、移动命令改变服务端位置、连续快照，以及第二客户端进程重新进入全新世界。
- Python 工具回归与全仓库源码行数检查。

仍缺图形客户端的快照消费、弹道与完整状态同步、心跳、延迟与丢包测试、增量快照、带宽/慢客户端控制、正式内容包握手、十人身份、装载屏障、重连和战争迷雾。开发快照包含整个训练世界，不能用于正式联网对局。Windows 与 Linux 尚未实测。

下一步把网络命令及快照接入客户端表现层，并保持离线模式可回归，再扩展多席位。

传输 API 参考：[Godot ENetMultiplayerPeer](https://docs.godotengine.org/en/stable/classes/class_enetmultiplayerpeer.html)、[Godot MultiplayerPeer](https://docs.godotengine.org/en/stable/classes/class_multiplayerpeer.html)。
