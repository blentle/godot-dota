# 双进程网络适配切片

当前交付是单席位、本机回环的开发验证：独立 Godot 服务端推进三路训练世界，图形客户端可通过专用参数发送操作并显示服务器快照。默认启动仍为离线选人。不能据此宣称十人对战、正式服务器或 M2 全部完成。

## 运行

指定 Godot 4.7.2 可执行文件，运行自动验证：

```sh
python3 tools/test_network_pair.py --godot .tools/Godot.app/Contents/MacOS/Godot
godot --headless --path game --script res://tests/test_network_authority.gd
godot --headless --path game --script res://tests/test_remote_world.gd
python3 tools/test_network_pair.py --godot .tools/Godot.app/Contents/MacOS/Godot --scene
```

其他系统把 `--godot` 改为实际可执行文件路径。脚本自动选择本机 UDP 端口，等待服务端就绪，先后启动两个客户端进程，确认退出后席位释放、第二次连接获得全新世界；超时或验证失败会报错，最终回收自己启动的服务端。端口选择存在操作系统释放与绑定间的竞争，冲突会明确失败。

手动运行时分别打开两个终端，启动开发服务端和可操作的图形客户端：

```sh
godot --headless --path game --script res://tests/network_server.gd -- --port=27883
godot --path game -- --connect-local=27883
```

图形入口固定使用近战卫兵；连接失败、席位占用及连接中断会显示状态页，并可返回离线选人。联网菜单只阻止本地操作，不暂停服务器；退出菜单可恢复操作，返回选人会断开连接。联网结算可返回离线选人，尚不能直接重开联网局。

`network_client.gd` 保留为无界面自动验证入口。普通 `--server` 仍拒绝启动，防止误认为已具备部署能力。自动场景测试的 `--scene --capture .impeccable/review` 会打开真实窗口并保存联网战场、断线页截图；测试服务端在连接后二十秒主动退出，用于验证失联处理。

## 模块责任

| 文件 | 责任 |
| --- | --- |
| `network/dev_protocol.gd` | JSON 解码、字段与类型白名单、版本身份 |
| `network/dev_authority.gd` | 连接控制权、序号、命令分发及固定步模拟 |
| `network/world_snapshot.gd` | 从规则世界提取独立值快照 |
| `network/dev_server.gd` | ENet 收发、连接超时、流量限制、定期快照 |
| `network/dev_client.gd` | 发送命令、接收与保存最新快照，不运行规则模拟 |
| `network/remote_world.gd`、`remote_state.gd` | 将快照适配到战场只读接口，将操作转为网络命令 |
| `bootstrap/network_flow.gd` | 连接、装载、运行、结算、断线和退出状态 |
| `simulation/terrain_layout.gd` | 图形地形与无界面服务端共享树木坐标 |
| `tools/test_network_pair.py` | 真实进程启动、超时、日志检查与回收 |

## 当前契约

服务端仅绑定 `127.0.0.1`，最多接受四个传输连接，仅一席位可完成握手。握手包含协议版本、开发构建标识、清单文件 SHA-256 和开发角色 ID；清单哈希不是完整资源包校验，也不构成认证。成功后连接绑定 `player` 控制权，重复握手和其他连接抢占均拒绝。

命令包含 `type=command`、固定开发比赛标识、从 1 开始的连续 `sequence`、`command` 与可选 `target`。支持移动、攻击、停止、保持、三种训练施法、购买和出售，全部调用已有规则入口；不允许客户端传入控制实体、伤害或金币。移动坐标校验类型、有限值和地图边界。

每个合法命令序号只执行一次；最近一次重复序号返回缓存确认，过期或跳号拒绝。格式校验失败不占用序号；规则层拒绝的合法命令占用序号并返回原因。最近确认只缓存一条，重复包即使更换载荷也不会再次执行。

权威规则每步推进 1/60 秒，每六步发一次全量快照；目前命令、确认和快照均用可靠 ENet 通道。快照包括 tick、确认序号、单位属性、状态与冷却、弹道、金币、装备、波次、召唤物和结算，以及服务端提供的购买/技能可用性。客户端拒绝旧 tick，不预测命中或本地扣费；等待确认期间有最多 32 条待确认命令的限制。此频率为开发验证值，不是最终性能预算，实际墙钟推进速度受模拟负载影响。

单个入站命令最大 4096 字节，每连接每秒最多 120 包，每次物理帧最多处理 128 包。超限连接断开；握手最长五秒，十秒没有入站消息也断开。图形客户端每秒发送心跳，五秒未收到服务器消息后冻结战场、关闭输入并显示断线提示。拥有者断开即销毁开发世界；下一次连接创建新世界，不属于重连恢复。

树木布局独立于渲染生成，服务端和图形场景使用相同固定坐标；服务器导航同时拥有树木和建筑障碍。远程门面的 `block` 只记录小地图显示数据，不创建寻路或战斗规则。

## 验证结果与缺口

已在 macOS Apple Silicon / Godot 4.7.2 上通过：

- 规则测试：错误版本、席位冲突、跨连接控制、额外字段、跳号、重复扣费、旧序号、异常坐标、业务失败确认、快照隔离及断开清理。
- 两个真实进程：拒绝错误版本、合法握手、购买、重复购买只扣一次、移动命令改变服务端位置、连续快照，以及第二客户端进程重新进入全新世界。
- 远程门面规则：没有本地移动、扣费或施法模拟；验证库存、派生属性、冷却、召唤、弹道和旧快照拒绝，及服务器树木阻挡。
- 独立服务端加真实图形窗口：鼠标购买、HUD 装备更新、远程移动、召唤物视图、菜单打开仍收快照、十一秒无操作心跳保活、服务端退出后的冻结与返回离线选人；完成两张截图检查。
- 离线选人/结算、训练场、兵线场景、商店和技能交互回归。
- Python 工具回归与全仓库源码行数检查。

仍缺移动插值、可靠战斗视觉事件（受击闪烁、挥砍与瞬发技能特效）、延迟与丢包测试、增量快照、带宽/慢客户端控制、正式内容包握手、十人身份、装载屏障、重连和战争迷雾。当前位置按快照更新，短于快照间隔的弹道可能无法呈现。开发快照包含整个训练世界，不能用于正式联网对局。Windows 与 Linux 尚未实测。

下一步补充网络表现平滑和战斗视觉事件，再扩展多席位及网络异常验证。
