# 三路兵线演练

本切片验证离线对局生命周期，不代表已经完成 DotA 6.83d。全部兵种、建筑参数与地图仍为开发值；没有正式英雄、正式装备数据、完整经验分配、战争迷雾或多人同步。

## 进入与操作

默认启动仍为单对手训练。在 Esc 菜单选择“三路兵线演练 / 重新开始”，或执行：

```sh
python3 tools/run_client.py -- --lanes
```

右键敌方单位或建筑指定攻击目标；A 追击当前目标，无目标时寻找最近的可攻击敌方。Q 对当前目标释放训练震击，建筑不会被眩晕。右键地面移动，S 停止，H 保持位置。菜单可切回单对手训练，也可重开当前模式；切换会清空本局状态。

## 已实现规则

- 双方各三路，每路三名近战小兵和一名远程小兵；开局第一波，此后每 20 秒尝试生成一整波。
- 同时存活小兵上限 96，超过容量时跳过整波，保证双方数量对称。尸体保留四秒后移除。
- 小兵沿路线推进，发现附近敌人后接近、攻击；导航寻找目标周边可攻击位置，避免把建筑中心作为移动终点。
- 每方三座防御塔、一座基地。塔射程 10，伤害 40，优先攻击范围内小兵。攻击前摇后发射速度为 20 的追踪投射物，抵达目标后结算伤害。
- 防御塔生命 650，基地生命 1500；本方三塔全部摧毁后，基地解除保护。建筑倒塌后的矮墩仍阻挡导航。
- 玩家补刀小兵获得 20 金币，摧毁塔获得 100 金币，重复伤害不重复发奖；英雄击杀与补刀分别计数。
- 基地摧毁后确定胜方，世界停止推进并拒绝移动、攻击和技能命令。玩家死亡时兵线仍继续运行。

## 验证与限制

Godot 4.7.2 在 macOS Apple Silicon 上通过兵线规则、原战斗规则、导航和两种模式的场景回归。兵线测试包括五分钟连续模拟、防御塔受击、容量限制、补刀唯一性和胜负冻结。原生窗口实测完成“兵线 → 单对手 → 兵线”菜单切换。Windows 与 Linux 尚未运行验收。

下一阶段需加入单位避让、多英雄经验分配及完整物品规则；再用已核验的 6.83d 数据替换开发参数。当前视觉依然是临时模型，不能计为 95% 原版 UI 还原。

## 远程攻击切片（2026-10-07）

远程兵生命 80、伤害 18、射程 6、攻击间隔 1.8 秒、弹道速度 16；使用较高的临时模型和金色尖帽与近战兵区分。这些是开发参数，尚非原版兵种数值。

弹道由独立 `projectile_system.gd` 模拟，以来源标识、阵营、伤害和目标生命代次快照进行结算。目标移动时追踪当前坐标；目标死亡、移除或复活则弹道失效。发射者死亡或清理不影响已发出的攻击，发射后属性变化也不改变在途伤害。每个弹道最多存活四秒，命中前移除以避免重入重复结算。

`projectile_view.gd` 只读取规则坐标并绘制阵营色光球；视图不参与伤害裁定。暂停与对局结束时，弹道跟随世界冻结。目前不包含障碍碰撞、闪避、反弹或弹道分裂。

新增 `test_projectiles.gd` 覆盖延迟命中、移动追踪、生命周期隔离、来源清理、伤害快照、无敌、重复伤害、前摇取消及超时清理；场景回归覆盖视图创建、暂停与销毁。
