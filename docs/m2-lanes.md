# 三路兵线演练

本切片验证离线对局生命周期，不代表已经完成 DotA 6.83d。全部兵种、建筑参数与地图仍为开发值；没有正式英雄、远程兵、装备、经验、战争迷雾或多人同步。

## 进入与操作

默认启动仍为单对手训练。在 Esc 菜单选择“三路兵线演练 / 重新开始”，或执行：

```sh
python3 tools/run_client.py -- --lanes
```

右键敌方单位或建筑指定攻击目标；A 追击当前目标，无目标时寻找最近的可攻击敌方。Q 对当前目标释放训练震击，建筑不会被眩晕。右键地面移动，S 停止，H 保持位置。菜单可切回单对手训练，也可重开当前模式；切换会清空本局状态。

## 已实现规则

- 双方各三路，每路四名近战小兵；开局第一波，此后每 20 秒尝试生成一整波。
- 同时存活小兵上限 96，超过容量时跳过整波，保证双方数量对称。尸体保留四秒后移除。
- 小兵沿路线推进，发现附近敌人后接近、攻击；导航寻找目标周边可攻击位置，避免把建筑中心作为移动终点。
- 每方三座防御塔、一座基地。塔射程 10，伤害 40，优先攻击范围内小兵。攻击前摇后即时命中，光束只是反馈，尚无弹道飞行模拟。
- 防御塔生命 650，基地生命 1500；本方三塔全部摧毁后，基地解除保护。建筑倒塌后的矮墩仍阻挡导航。
- 玩家补刀小兵获得 20 金币，摧毁塔获得 100 金币，重复伤害不重复发奖；英雄击杀与补刀分别计数。
- 基地摧毁后确定胜方，世界停止推进并拒绝移动、攻击和技能命令。玩家死亡时兵线仍继续运行。

## 职责边界

| 文件 | 职责 |
| --- | --- |
| `lane_layout.gd` | 三路与建筑坐标 |
| `lane_factory.gd` | 原型单位参数及创建 |
| `lane_ai.gd` | 兵线推进和防御塔目标策略 |
| `lane_match.gd` | 波次、容量、清理、保护和胜负 |
| `combat_system.gd` | 通用单位登记、前摇、伤害与奖励 |
| `army_view.gd` | 小兵视图、建筑血条、倒塌及命中反馈 |

## 验证与限制

Godot 4.7.2 在 macOS Apple Silicon 上通过兵线规则、原战斗规则、导航和两种模式的场景回归。兵线测试包括五分钟连续模拟、防御塔受击、容量限制、补刀唯一性和胜负冻结。原生窗口实测完成“兵线 → 单对手 → 兵线”菜单切换。Windows 与 Linux 尚未运行验收。

下一阶段需加入近战/远程兵差异和弹道、单位避让、经验升级及装备规则；再用已核验的 6.83d 数据替换开发参数。当前视觉依然是临时模型，不能计为 95% 原版 UI 还原。
