# 选人、结算与重开

本切片打通离线单局入口与退出。三种角色是机制验证配置，共用 Q / W / E 训练技能，不是 DotA 6.83d 正式英雄；界面也不是原版选人界面的验收结果。

## 操作

普通启动进入选人页。选择近战卫兵、远程射手或施法学徒，再选择三路兵线演练或单对手训练。角色的生命、魔法、攻击、射程、间隔与弹道参数会实际应用于规则世界。三路模式初始 300 金币；单对手模式没有持续收入或基地胜负。

三路模式摧毁基地后显示胜方、耗时、角色等级、波次、金币、击杀、阵亡、补刀与建筑数，以及结束时装备。可同角色再开一局或返回选人；战场 Esc 菜单也可返回选人。重开会清空旧世界、装备、召唤物、金币和等级，只保留角色与模式选择。

命令行 `--lanes` 或 `--training` 使用近战卫兵直接开局，供开发验证使用；`--smoke-test` 保持自动进入训练场的行为。

## 职责与状态

- `hero_profiles.gd` 管理开发角色配置，规则世界仅允许开局前应用。
- `client_flow.gd` 管理选择、运行、结算三个状态及场景销毁，界面只发出开始、返回或重开意图。
- `match_result.gd` 提取值类型快照，返回副本防止界面修改规则库存。
- `selection_screen.gd`、`result_screen.gd` 分别呈现入口与结算，`session_style.gd` 共用视觉样式。
- 基地死亡立即锁定战斗结束状态；同一模拟步内的后续弹道或攻击不能改变胜负。结算时关闭战场输入与推进，防止快捷键穿透。

## 验证与限制

`test_session_rules.gd` 验证配置校验、远程攻击、开局锁定、快照隔离和同帧胜负冻结。`test_client_flow.gd` 通过视口鼠标事件验证选择、开始、双方基地结算、重开清理、返回及模式切换。`capture_session.gd` 可通过 `--output-dir=绝对路径` 输出选人与结算截图。

本轮已在 macOS Apple Silicon 上验证；Windows、Linux 尚未验收。没有多人选人、平台统计、存档或服务端战果提交，不将开发对局记入平台战绩。下一切片按路线图验证双进程网络适配。
