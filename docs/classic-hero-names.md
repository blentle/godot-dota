# 英雄专名与称号显示

原生英雄面板的姓名行与等级/称号行承担不同职责。此前两行都使用目录 `name`，导致 Zeus、Nevermore 等地图专名丢失。本轮仅修正表现数据与显示，不修改英雄属性、技能、生命或训练规则。

## 原始配置与校对策略

地图 `Propernames` 保留重复项。例如 `Hmbr` 有一次 Merlini、七次 Zeus；`Nfir` 有十次 Nevermore、一次 YaphetS。旧目录只存去重后的列表，无法据此选择常见名。

目录现在同时保存：`proper_names`（原有去重列表，保持兼容）、`proper_name_pool`（去除颜色控制符后的原始重复列表）、`display_name`（频次最高的专名，平频时保留首次出现项；无专名时回退称号）。这只是校对模式的确定性显示策略，不模拟 Warcraft III 随机选名，不把目录权重当作运行时概率验收。

HUD 姓名行显示 `display_name`；下方显示“第 N 级 + 称号”。等级仍读取真实训练快照。没有把地图编辑器基础属性填到训练战斗属性中；力量、敏捷、智力和护甲仍保留未实现标记。

## 验证与边界

英雄切换回归检查 Zeus/Nevermore 的常见名、专名/称号分行以及规则状态只读。macOS 1024×768 实机截图检查姓名与等级行。原始地图仍采用已记录 SHA-256 的候选，不表示官方版本已独立核实。原版行距、基线、纪念名颜色和实际随机选名尚未验收，Windows/Linux 未实测。

本轮整工程回归、112 项目录专名一致性、1570 项来源摘要及 187 个源码文件行数检查通过。
