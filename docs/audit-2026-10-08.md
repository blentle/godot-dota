## 已修复的问题

| 问题 | 影响 | 处理与证据 |
| --- | --- | --- |
| 工程物理帧率为 30 Hz，服务端每帧只推进 1/60 秒 | 未过载时也会半速运行 | 服务端显式切换 60 Hz，握手和规则共用频率常量；新增时钟回归 |
| 仅以距离判断复活是否应立即就位 | 近距离复活可能滑行 | 独立表现插值组件检查生命代次、死亡状态及首次出现 |
| 弹道持续外推、关闭后可再应用快照 | 停包时弹道继续飞行，迟到数据可能恢复界面 | 最多推进 0.1 秒；关闭后拒绝快照并清空插值状态 |
| 视觉事件缺少身份与生命代次 | 重复事件或旧生命代次事件可能重复/错误播放 | 单调事件序号去重、生命代次过滤；缓冲溢出计数 |
| 异常测试将移动布尔结果与字符串比较，未推进显示插值 | 测试不能正确判断恢复与位置收敛 | 按接口返回类型断言，显式推进测试客户端表现时间 |
| 截图参数出现在引擎与用户参数分隔符之前 | 测试可能运行却未真正保存截图 | 集中构建命令，参数单测及实际截图验证 |
| 并发测试首个客户端失败后未回收其余进程 | 测试泄漏子进程 | 统一 finally 清理并等待退出；增加失败路径单测 |
| 只等待事件状态，未等待下一次物理帧绘制光环 | 特效场景测试偶发失败 | 等待实际视图可见后断言 |

## 尚未完成的产品能力

最多四个连接各自运行独立训练世界，不是两人或十人同局。还没有正式平台服务、账号/票据、同局控制权、装载屏障、重连恢复、战争迷雾、正式英雄数据与资源包。

事件缓冲每窗口最多 64 条，溢出会记录并丢弃视觉事件；短于快照窗口的弹道仍可能没有轨迹。异常测试只模拟服务端阻塞和客户端停读，尚未注入真实 UDP 丢包、乱序及链路时延。完整快照使用可靠通道，慢客户端带宽与背压还需专门设计。

仅在 macOS Apple Silicon 运行本轮验证。Windows、Linux、macOS Intel、导出包、签名和跨平台联机尚未验收；导出预设存在不代表安装包已发布。原始地图和视觉参照尚未核验，不能宣称 UI 95% 或全英雄完成。
