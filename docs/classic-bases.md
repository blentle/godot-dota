# 原始基地外观

本轮按继续视觉还原的要求，替换经典训练场两个基地的几何占位。地图 unitui.slk 中 etol 使用 war3mapImported/final_export、缩放1.2；unpl 使用 doodads/cinematic/lichking/lichking、缩放1。模型优先从固定摘要地图提取，再由既有经典镜像补齐依赖；出处及摘要保存在资源来源和转换清单。

base_view 复用塔视图的只读状态、死亡与动画生命周期。基地不实现新的攻击方式，不修改训练保护、位置、碰撞或胜负规则。旧入口仍用训练几何，原始模型加载失败也回退占位。

原始模型引用 sharedmodels/teamglow00.tga，本轮补充既有 tga-js 解码到 PNG，再由相同原始摘要校验入口生成并记录出处，运行时将 .tga 路径映射为 PNG。首次回归明确报告缺少该纹理，补齐后重跑。

新增基地加载、零时间暂停及死亡状态专项；既有塔测试仍验证仅六座塔，避免把继承相同生命周期的基地误计为防御塔。截图工具支持 --bases，macOS 图形截图检查。原版布局、大小、朝向、光照混合及逐像素对照未验收；Windows/Linux未实测。

完整工程回归通过；209个源码文件未超限，1367张二次幂PNG、1606项来源摘要检查通过。只读审查无阻塞；LichKing源模型只有Stand/portrait，无Death序列，死亡后保持源姿态，不能宣称已还原天灾基地倒塌动画。

## 可追溯配置目录

`python3 -m tools.classic_art.build_tower_catalog` 现在同时生成 base-catalog.json，复用原有三份配置摘要校验，保留基地模型、缩放、RGB和动画标签。运行时读取该目录，移除写死路径和缩放。两项配置均为白色且无附加动画标签，当前画面不应因此发生变化。基地专项、资源和源码行数检查通过；本轮未追加图形验收或完整工程长局。
