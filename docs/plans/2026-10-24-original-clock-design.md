# 原始顶部时钟模型接入设计

## 目标与已选方案

用户选择接入原始时钟模型，先验证朝向、材质和两段原始动画，再替换现有静态太阳截图。本轮不新增昼夜玩法、视野规则或服务器时间协议。

考虑过两种方式：修正静态图集截取，改动较小但仍无法表达原始模型；接入原始模型，能复用已实现的骨骼/材质加载并保留模型动画，但需要独立验证取景和混合。用户已选择后者。

## 场景与资源

- 保留顶部 Clock 区域 (435,-7)–(589,70)，画布仍为 1024×768。
- 以独立 Control/TextureRect 组件承载 SubViewport，内部采用二次幂分辨率、透明背景、独立 3D 世界；关闭抗锯齿，输出最近邻采样，不拦截鼠标。
- 复用 `model_view.gd`，读取已核验来源的 MDX v800 转换数据及原始纹理；不添加依赖、程序太阳或现代化光效。
- 已导入 `humanui-timeindicator` 包含 13 个网格、Stand 与 Stand Alternate 两段序列，没有模型相机。先检查网格范围及原始 UI 配置，用专用正交相机取景，不套用英雄头像相机。
- 模型自带边框与种族静态边框不得重复叠加；先验证当前近卫 NightElf 外观的对应关系，其他种族不能未经比较宣称一致。

## 动态职责

场景描述布局、相机和视口；独立脚本处理模型绑定、原始序列取样、暂停及显示。暂停时冻结表现时钟，恢复后继续，重新绑定释放旧视图。

先提供明确的原始动画时间点采样以校对两段序列。模型动画属于表现预览，不推断为实际游戏时刻；地图初始时间与模型帧的对应在核验前不宣称已完成。实际昼夜时钟日后由权威状态输入，不由 UI 写入或推导战斗规则。

## 验证与交付

1. 先验证原始模型/纹理可读、两段序列存在，以及重复绑定、暂停/恢复和固定时间采样。
2. 实机截取两段序列的多个固定时间点，检查正反面、裁剪、透明背景、边框叠加和混合。若缺少关键渲染支持，明确记录，不用替代美术掩盖。
3. 替换静态白色圆面后运行相关 HUD 回归、工程检查、资源摘要及单文件 500 行检查；按模块本地提交，不自动推送。
4. 完成基础接入不等于原版像素验收。Windows、Linux 未实测；原版时间映射、种族一致性和精确混合保留为独立验收项。
