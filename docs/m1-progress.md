# M1 离线操作原型

本文保留 M1 阶段验收记录。后续训练战斗与代码拆分见 [M2 开发切片](m2-combat.md) 和 [源码职责](code-structure.md)；下方“未完成”列表描述当时的 M1 状态。

本轮范围：可以操作的游戏窗口，不代表完成 6.83d 游戏，也不计入全英雄或 UI 95% 验收。

## 已实现代码

- 3D 俯视场景：三路示意地形、河道、桥、林区、双方基地与塔。
- 训练卫兵：左键选择、右键移动、M 指定移动、S 停止、H 保持。
- AStar 网格绕开树木和建筑，地图边界限制；规则更新与表现分离。
- 方向键平移、滚轮缩放、F1/空格镜头返回；菜单可开启边缘滚屏。
- 小地图显示道路、树林、基地、单位和镜头范围；左键移动镜头、右键下令。
- 经典布局研究 HUD：顶部资源/时间、底部小地图、头像、状态、背包、4×3 指令区。
- Esc/F10 打开离线暂停菜单，支持恢复和退出；HUD 拦截鼠标，避免点界面时误下令。
- Windows、macOS、Linux 导出配置（尚未生成或验证安装包）。

## 操作与运行

```sh
godot --path game
godot --headless --path game -- --validate-content
godot --headless --path game -- --smoke-test
godot --headless --path game --script res://tests/test_training.gd
```

本机工程内安装时可用 `.tools/Godot.app/Contents/MacOS/Godot` 替代 `godot`。需 4.7.2。首次打开可运行 `--headless --editor --path game --quit` 执行导入。

## 未完成与已知限制

地图几何为操作验证示意，未从原地图提取。模型为临时程序几何，尚无原版动画、材质和音效。UI 尚未完成原版截图逐项比对。训练卫兵不是任何已完成的 DotA 英雄；血量/魔法/金币不填造假数值，战斗与装备按钮禁用。

暂不包含战斗、兵线、迷雾、高低地、商店、选人、英雄技能、网络同步或平台。寻路为 1 单位网格，尚无动态单位避让和转身速度规则。河道当前可通过，未完成地形碰撞规则。字体使用系统中文字体候选，正式发行前须打包验证跨平台一致的字体。

16:9 逻辑画布为 1280×720，其他比例保留黑边；经典 4:3 与真正的宽屏 HUD 适配仍需后续实现。macOS 包签名关闭，仅作为本地开发导出；正式发布签名见 platforms.md。
