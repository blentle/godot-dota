# 原始属性图标接入

按用户确认的范围，将原生 HUD 的力量、敏捷、智力文字标签替换为已导入的原始 `infocard-heroattributes-str/agi/int` 纹理。使用 TextureRect、最近邻过滤、禁用重复，不生成替代图标，不改变训练规则。

属性区位置仍为 (531,658)，三行局部起点为 (0,0)、(0,27)、(0,54)，图标显示框 20×20；数值列仍从局部 x=60 开始。未知属性继续显示“—”，不填入地图基础属性冒充训练数值。纹理文件本身保持原始二次幂尺寸，显示框无需二次幂。

回归先确认原场景缺少三个 Icon 绑定，再验证接入后纹理有效且未知数值仍为空。macOS 1024×768 实机截图可见三个独立原始图标。此为现有固定布局上的接入，不表示图标位置、尺寸已完成 Warcraft III 1.26 像素对照；Windows/Linux 尚未实测。
