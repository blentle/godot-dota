# 原始顶部时钟模型

按已批准设计，当前近卫 HUD 使用原始 `humanui-timeindicator` 的 13 个网格与两段原始序列，替换此前固定太阳裁图。保留 Clock 的 (435,-7)–(589,70) 区域及 1024×768 画布；不新增昼夜玩法、视野或服务器协议。

## 模型与取景

专用 TextureRect 输出 256×128 透明 SubViewport，独立世界、无抗锯齿、最近邻采样。模型框的原始 XY 范围为 x=.337..465、y=.536..600、z=.45454；恢复原始轴向，放大 1000 倍，相机位于 (401,568,1454)，朝 -Z，正交垂直尺寸 64。没有套用英雄的坐标旋转或头像相机。

原始 UI 模型骨骼 `sunrise/set` 含 Godot 不允许的 `/`。运行时将冒号和斜线替换为下划线，并保留 ObjectId 索引及源数据；否则骨骼添加失败会引起后续索引错位。补齐 `textures/humanuitile-timeindicator.png` 和 `textures/magicglow.png`，来源仍为固定经典副本并验证 Git blob 摘要。

近卫使用原始 NightElf 时间框纹理替换模型中框材质，不再叠加旧静态拼图。Human/Undead 保留原静态入口；没有把当前近卫检查推广为所有种族已验收。重新绑定后保持已配置皮肤。

## 动画及边界

`clock_view.gd` 提供绑定、精确序列采样、推进和暂停；HUD 同步训练暂停状态，普通状态刷新不重建模型。Stand 与 Stand Alternate 可在 0、15、30 秒独立校对。当前 60 秒源动画循环仅为表现预览，并不代表地图时刻；初始 6 点与模型帧、实际昼夜周期的对应尚未核验。

截图可见原始盘面及指示灯变化，六个时间点渲染无错误。透明像素检查中，Stand 的 0/15/30 秒分别为 14748/10839/14816 个全透明像素，右下角 Alpha 均为 0。完整近卫 HUD 截图确认没有同时显示两套时钟框；底部黑色遮挡及边框精确裁剪仍需原版逐像素比较，不能据此认定整体画面完全还原。

## 验证

- `test_classic_clock.gd`：组件缺失时先失败；原始网格/骨骼数量、两段序列、暂停/恢复、零推进和重复绑定。
- `test_classic_clock_hud.gd`：静态入口时先失败；模型接入、暂停同步、刷新不重建和训练规则只读。
- `capture_classic_clock.gd`：图形模式保存两段序列六个时间点至 `/tmp/classic-clock-序列-秒数.png`。
- 整工程回归通过；最终重绑修正另行重跑专项测试。资源检查为 112 位英雄、1354 张二次幂 PNG、1572 项来源；192 个源码文件无超过 500 行。

macOS Apple Silicon 已检查；Windows/Linux、原版时间映射、种族一致性、精确混合和像素对照未验收。
